Run it yourself

Three commands

git clone https://github.com/Divya2030/GreenSilicon
cd GreenSilicon
./scripts/dev.sh --prod   # local chain + deploy + seed + API + UI at http://localhost:8000

Requires Node 20+ and Python 3.12+. Works without an AI key (offline auditor); set ANTHROPIC_API_KEY to enable Claude. Contract tests: cd contracts && npx hardhat test · Backend tests: cd backend && .venv/bin/python -m pytest
